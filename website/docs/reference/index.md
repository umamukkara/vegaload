# Reference

Plain lookup pages. For how-to steps, use the [Guides](../guides/index.md).

- [Commands and flags](./cli.md): every command, every `run` flag, and the exit codes.
- [Protocol options](./protocol-options.md): the `-opt` keys each protocol accepts.
- [JSON report](./report-json.md): every field in the file that `-out` writes.

These pages come from the 0.9.0 binary. To see the same facts on your machine, run `vegaload help`, `vegaload run -h` and `vegaload protocols`.
